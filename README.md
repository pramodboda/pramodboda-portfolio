## 🚀 Getting Started

1️⃣ Clone the repo
```bash
git clone https://github.com/pramodboda/pramodboda-portfolio.git
cd portfolio
````
2️⃣ Install dependencies
```bash
npm install
```
3️⃣ Run locally
```bash
npm run dev
```
📦 Build for Production
```bash
npm run build
```
